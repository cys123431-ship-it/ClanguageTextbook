한국어 C언어 통합교과서의 집필 및 검증 상태를 공개합니다.

## 📊 제작 진행 현황

![집필 상태](https://img.shields.io/badge/집필-진행중-blue) ![검증 상태](https://img.shields.io/badge/최종검증-미완료-lightgrey)

**전체 진척률:** 산정 대기 (전체 절 목록과 검증 완료 절 수 확정 후 계산)

> 정확하지 않은 퍼센트를 임의로 표시하지 않습니다. 기존 구판 집필분은 개정판 완료율에 포함하지 않습니다.

| 작업 단계 | 상태 |
|---|---|
| 전체 초안 집필 | ⏳ 진행 중 |
| 원본 두 권 학습목표 전수 대조 | ⬜ 미완료 |
| C 예제·DOCX 전체 검증 | ⬜ 미완료 |
| 최종 결과물 GitHub 업로드 및 재확인 | ⬜ 미완료 |

### 최근 완료된 작업

새 개정판의 검증된 완료 절: 아직 GitHub에 확인된 기록 없음.

자세한 기계 판독용 상태: [progress.json](progress.json)

## 진행률 갱신 규칙

- 매 집필 회차의 결과를 검증한 후에만 완료 절 수와 최근 완료 절을 갱신합니다.
- 전체 절 목록이 확정되면 `완료된 절 / 전체 절 × 100`으로 집필 진행률을 계산합니다.
- 집필 진행률과 **최종 출판 완료**는 별개입니다. 전수 대조·검증·GitHub 업로드까지 끝나야 최종 완료로 표시합니다.
- 변경 시 README의 상태·표·최근 완료 절 및 `progress.json`을 함께 갱신하고 커밋합니다.
- 최종 결과물은 DOCX·C 예제 ZIP·범위 대조표·검증 기록을 대상으로 합니다. 저작권 보호 원본 PDF는 올리지 않습니다.

> 참고: 이 페이지는 GitHub에서 표시되는 진행 현황판입니다. 예약 작업에서 실제 파일을 갱신해야 자동으로 최신 상태가 반영됩니다.
