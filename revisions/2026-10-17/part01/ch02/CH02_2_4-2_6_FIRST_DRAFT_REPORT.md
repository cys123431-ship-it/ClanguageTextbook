# C언어 종합교과서 · 2026-10-17 회차 작업 기록

## 실제 집필·재활용
- Library에 보관된 제2장 2.1~2.3 DOCX의 본문을 실제로 불러와 **재사용**했다.
- 신규 **2.4 Visual Studio 빈 프로젝트와 파일 등록**, **2.5 소스/빌드/실행 경로와 한글 인코딩**, **2.6 GCC/Clang/MSVC 옵션과 경고**를 추가했다.
- 누적 제2장 DOCX 2.1~2.6은 **22쪽**이며 1차 초안 상태다.
- 새로운 예제 소스 8개(헤더 1개 포함), 빌드 단위 6개를 작성했다. GCC·Clang에서 각 6개 빌드 단위를 C11 엄격 옵션으로 컴파일/실행해 **12/12** 통과했다.
- Visual Studio/MSVC는 현재 Windows 환경이 없어 실제 실행하지 못했다. UI 안내는 버전별 차이를 명시했다.

## 상태를 과장하지 않기
- 전체 책은 아직 미완성이다. 제2장도 원서 개별 학습목표 전수 대조 전이므로 장 완료 판정을 하지 않는다.
- 임시 1.1~1.115절의 최종 이관은 아직 전수 검증되지 않았다.
- 앞서 제작한 제17장 17.1~17.7 부분 초안도 보존한다.
